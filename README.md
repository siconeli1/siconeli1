## About me

I am an Information Systems student at **IFSP** and a software developer from
Brazil. My journey started with Java, object-oriented programming, and desktop
applications, then expanded into modern full-stack development.

Today, I build practical products that connect polished interfaces to real
business logic: authentication, payments, databases, external APIs, security
rules, automated tests, CI, and cloud deployment. I enjoy turning ideas and
academic foundations into complete, usable software.

- Building with **Next.js, React, TypeScript, Java, and PHP**
- Working with **Supabase, Firebase, PostgreSQL, and REST APIs**
- Interested in software architecture, secure systems, and product development
- Currently deepening my knowledge of Laravel and modern web engineering
